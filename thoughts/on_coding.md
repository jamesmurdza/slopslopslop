# On Coding

There's something meditative about debugging - you enter a flow state where time ceases to exist, and suddenly it's 3 AM.

The best code is the code you don't have to write. The second best is code that reads like a story.

Every programmer has a love-hate relationship with semicolons. Those who say otherwise are lying.

Sometimes the bug is not in the code, but in the assumptions we made three weeks ago when we thought we understood the requirements.
